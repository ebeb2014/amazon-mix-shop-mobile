# Amazon Mix Shop Mobile

PWA mobil pentru administrarea Amazon Mix Shop.

## V1
- Login Administrator prin Supabase Auth
- Dashboard
- Stoc + căutare
- Istoric vânzări
- Cereri de aprobare + Aprobare/Respinge
- Instalabilă ca PWA pe iPhone / Android

## Următorii pași
1. Publicare într-un repository/site separat.
2. Login pe username `admin` fără expunerea emailului.
3. Legarea operațiilor desktop marcate `Necesită aprobare` la `ams_approval_requests`.
4. Jurnal activitate.
5. Permisiuni mobile pentru angajați.
6. Push notification / badge real pentru aprobări.
